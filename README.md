# Business Card

A simple front-end web project that displays a digital business card using HTML and CSS only.

## Features

- Clean, centered card layout with CSS Flexbox
- Profile image with rounded avatar
- Contact information (name, title, email)
- Responsive design

## Technologies

- HTML5
- CSS3

## Project Structure

```
Business Card/
├── index.html        # Main HTML file
├── style.css         # Stylesheet
└── peer image.jpg    # Profile photo
```

## Usage

Open `index.html` in any web browser to view the business card.
